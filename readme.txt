A free, open-source, modular toolkit for Bricks Builder. Newsletter actions, inline conditions, image focus point.

== Description ==
Built by Amel-Nokoe. Contributors: zynkara, aetherisinnovate, amel65, kelvinpiousnokoe.
Website: https://zynkaratech.com

One plugin. Three small modules. Off = loads nothing.

1. Image Focus Point — pick where hero images crop on mobile. Pure CSS, no frontend JS.
2. Inline Conditions in Dynamic Data — {post_meta_stock:if>0:In Stock|Out of Stock} instead of duplicating elements.
3. Newsletter Form Actions — Bricks Form signups to MailPoet (no API key), MailerLite, or Kit (ConvertKit).

No paywalled modules. No lock-in. If you deactivate, your pages keep working.
Tested on WordPress 7.1.4.

== Installation ==
1. Install Bricks Builder theme and activate it.
2. Upload zynkara-toolkit to /wp-content/plugins/ and activate.
3. Go to Tools > Zynkara to enable modules.
4. For Newsletter: Bricks Form > Actions > Add action > Zynkara Newsletter.
